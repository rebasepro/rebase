NOTE: {{ .Values.api.replicas }} API replicas, and sharedState.channelBusConfigured is false.
The runtime's default channel bus is in-memory, so realtime BROADCAST and
PRESENCE do not cross processes — a subscriber on one pod will not see a
message published on another. Ordinary collection subscriptions are unaffected
(those go through Postgres CDC). If your project uses broadcast or presence,
set `realtime: { bus: { type: "postgres" } }` in its config and rebuild the
bundle; the chart cannot do that for you, because it lives in your code.
{{- end }}
