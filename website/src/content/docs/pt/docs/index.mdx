## O que é o Rebase?

O Rebase é o **backend open-source para PostgreSQL**, com um **painel de administração** para a sua equipe, desenvolvido com React e TypeScript. Ele oferece tudo o que você precisa para criar uma aplicação pronta para produção no **PostgreSQL**:

- **Schema as Code** — Declare suas tabelas do Postgres em TypeScript, cada uma com uma postura obrigatória de segurança a nível de linha (row-level security). O Rebase gera as tabelas e suas políticas, endpoints de API REST, um SDK tipado e uma UI de CRUD completa a partir dessa única fonte de verdade.
- **Painel de Administração Instantâneo** — Um painel elegante e rápido baseado em React com tabelas estilo planilha, listas, formulários, quadros Kanban, edição inline e sincronização em tempo real.
- **Backend Integrado** — Autenticação (senhas, magic links, códigos únicos, MFA, chaves de API e doze provedores OAuth/OIDC), armazenamento de arquivos (local, S3 ou GCS), Row Level Security, histórico de entidades e tempo real via WebSocket — tudo integrado.
- **Radicalmente Extensível** — Se você consegue criar em React, você pode adicionar ao Rebase. Campos personalizados, visualizações personalizadas, plugins e acesso completo aos hooks internos.

:::tip
O Rebase funciona de ambas as maneiras, e seu código não muda entre elas. **Hospede você mesmo (Self-host)** — você é o dono dos dados, do código e da máquina onde ele executa. Ou faça o deploy do mesmo projeto no **Rebase Cloud** ([app.rebase.pro](https://app.rebase.pro)), que é o mesmo Rebase gerenciado para você; já está em funcionamento com tenants reais hoje e liberando acesso em lotes durante o beta privado. Pense nele como uma alternativa open-source ao Supabase ou Retool, onde *você* decide quem o opera.
:::

## Escolha o seu caminho

O Rebase é um backend e um painel de administração que compartilham o mesmo servidor. Comece por aquele que você procura:

| Eu quero… | Comece aqui | O que você recebe |
|---|---|---|
| **Um backend e um painel de administração** | [Quickstart](/docs/getting-started/quickstart/) | Tabelas em TypeScript, uma UI de CRUD gerada, uma API REST, autenticação, armazenamento e tempo real |
| **Apenas a API, sobre o meu próprio banco de dados** | [Backend only](/docs/getting-started/headless/) | Uma API REST headless e SDK sobre o seu PostgreSQL existente — sem painel de administração, sem arquivos de tabela |

Nenhuma das opções é um caminho sem volta: um projeto headless pode ganhar um painel de administração adicionando um frontend, que renderiza cada tabela que o backend disponibiliza, e ambos podem definir suas tabelas em `backend/schema/` quando quiserem tê-las como código.

## Início Rápido

```bash
pnpm dlx @rebasepro/cli init my-app
cd my-app
```

O `init` gera um `.env` pronto para execução — sem necessidade de edição. Em seguida:

```bash
pnpm install
pnpm run dev
```

Essa é toda a execução inicial. Não há banco de dados para instalar nem etapa de schema: sem nenhuma `DATABASE_URL` definida, o `rebase dev` inicializa um PostgreSQL gerenciado (PGlite) no diretório do projeto, gera o schema a partir de suas tabelas e cria as tabelas na inicialização.

**Verifique as URLs na saída do terminal.** O `rebase dev` escolhe uma porta livre por projeto em vez de portas fixas, de modo que elas variam entre projetos e máquinas. A primeira conta cadastrada se torna o administrador — na sua máquina. Uma implantação em produção, por outro lado, define seu admin através de `REBASE_ADMIN_EMAIL` e `REBASE_ADMIN_PASSWORD` (consulte [Configuration](/docs/getting-started/configuration/)).

Para usar o seu próprio Postgres, descomente `DATABASE_URL` no `.env` e execute `pnpm run dev` novamente.

→ Siga o [Guia de início rápido](/docs/getting-started/quickstart) completo para um passo a passo detalhado, incluindo como conectar o seu próprio banco de dados.

## Recursos Principais

| Recurso | Descrição |
|---------|-------------|
| **Visualizações em Planilha** | Tabela rápida e virtualizada com edição inline, filtros, ordenação e busca por texto |
| **Visualização em Lista** | Visualização em lista vertical limpa e responsiva para qualquer tabela |
| **Quadro Kanban** | Visualização em quadro com arrastar e soltar (drag-and-drop) agrupada por qualquer coluna enum |
| **Relações** | Um-para-um, um-para-muitos, muitos-para-muitos com tabelas de junção e joins multi-hop |
| **Row Level Security** | Políticas de RLS do Postgres compiladas a partir do `rls` que cada tabela deve declarar |
| **Autenticação** | JWT + refresh tokens, doze provedores OAuth/OIDC, magic links, códigos de uso único, TOTP MFA, chaves de API com escopo, controle de acesso baseado em funções (RBAC) |
| **Armazenamento de Arquivos** | Sistema de arquivos local, compatível com S3 ou Google Cloud Storage, com campos de upload e navegador de arquivos |
| **Sincronização em Tempo Real** | Atualizações ao vivo via WebSocket em todos os clientes conectados |
| **Histórico de Entidades** | Trilha de auditoria completa para cada criação, atualização e exclusão |
| **API REST** | Endpoints de CRUD gerados automaticamente para cada tabela |
| **Importação/Exportação de Dados** | Importação de CSV, JSON e Excel com mapeamento de campos; exportação em CSV/JSON |
| **SDK Tipado** | SDK JavaScript com tipagem estática (type-safe) para suas aplicações de frontend |
| **Sistema de Plugins** | Estenda qualquer parte da UI — barra de ferramentas, formulários, campos, página inicial |
| **Aprimoramento de Dados com IA** | Preenchimento automático com LLM para campos de texto |
| **Tarefas Agendadas (Cron Jobs)** | Tarefas em segundo plano agendadas com monitoramento, logs e painel no Studio |
| **Funções Personalizadas** | Rotas Hono baseadas em arquivos montadas automaticamente com middleware de autenticação e acesso ao banco de dados |
| **Serviço de E-mail** | SMTP integrado para redefinição de senha, verificação e e-mails transacionais |
| **Database Branching** | Cópias isoladas e instantâneas do seu banco de dados para dev, staging ou testes |
| **Webhooks** | Notificações de saída assinadas com HMAC em INSERT, UPDATE e DELETE |
| **Canais de Transmissão (Broadcast)** | Canais WebSocket para troca de mensagens em tempo real entre clientes conectados |
| **Rastreamento de Presença** | Monitore usuários online e sincronize o estado compartilhado entre os participantes |
