
## Props

| Prop | Type | Required | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | yes |  |
| `value` | `string` | — | Identifies this menu to the parent Menubar's `value`/`defaultValue`. |

## Example

This is the example the design-system sync renders and verifies for this component.

```tsx
import { Menubar, MenubarMenu, MenubarTrigger } from "@rebasepro/ui";

export const Closed = () => (
    <div className="p-4">
        <Menubar>
            <MenubarMenu>
                <MenubarTrigger>File</MenubarTrigger>
            </MenubarMenu>
            <MenubarMenu>
                <MenubarTrigger>Edit</MenubarTrigger>
            </MenubarMenu>
            <MenubarMenu>
                <MenubarTrigger>View</MenubarTrigger>
            </MenubarMenu>
        </Menubar>
    </div>
);
```
