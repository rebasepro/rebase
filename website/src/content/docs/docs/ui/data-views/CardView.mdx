## Example

This is the example the design-system sync renders and verifies for this component.

```tsx

export function ProjectGrid() {
    return (
        <div style={{ height: 480 }} className="w-full overflow-auto rounded-lg border border-surface-200 dark:border-surface-800">
            <CardView<SampleProject>
                data={SAMPLE_PROJECTS}
                dataLoading={false}
                noMoreToLoad={true}
                paginationEnabled={false}
                size="m"
                selectionEnabled
                renderCard={renderCard}
            />
        </div>
    );
}
```
