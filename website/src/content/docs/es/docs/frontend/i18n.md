## Resumen

Cada cadena que muestra el panel de administración proviene de una clave. Se incluyen
siete configuraciones regionales: inglés, español, alemán, francés, italiano, portugués
e hindi, y un proyecto puede anular cualquier clave, añadir su propio idioma o traducir
sus propios componentes usando la misma tabla.

Tres elementos hacen el trabajo:

| | |
|---|---|
| `<Rebase locale>` | en qué idioma comenzar |
| `<Rebase translations>` | qué dice cada clave, por configuración regional |
| `useTranslation()` | leer una clave desde tu propio componente |

## Elegir el idioma

```tsx
<Rebase client={client} authController={authController} locale="es">
    <RebaseCMS tableCustomizations={tableCustomizations}/>
    <RebaseShell title="My App"/>
</Rebase>
```

`locale` es el idioma *inicial*. La elección de un usuario que seleccione uno en el
menú de idiomas se recordará en su navegador y tendrá prioridad sobre la prop en su
próxima visita; cambiar `locale` en el código no anulará la configuración de un
usuario. Cualquier elemento para el que Rebase no tenga una cadena recurrirá al
inglés por defecto en lugar de mostrar una clave.

## Cambiar lo que dice una cadena

`translations` se organiza por configuración regional y luego por clave. Es parcial:
indica las pocas que deseas cambiar y todo lo demás permanecerá como estaba.

```tsx
<Rebase
    client={client}
    authController={authController}
    translations={{
        en: { save: "Publish", delete_confirmation_title: "Unpublish?" },
        es: { save: "Publicar", delete_confirmation_title: "¿Despublicar?" }
    }}
>
    <RebaseCMS tableCustomizations={tableCustomizations}/>
    <RebaseShell title="My App"/>
</Rebase>
```

La misma estructura permite añadir un idioma que Rebase no incluye de fábrica.
Proporciónale un conjunto completo de claves y asigna `locale` a dicho idioma:

```tsx
<Rebase
    client={client}
    authController={authController}
    locale="nl"
    translations={{ nl: { save: "Opslaan", cancel: "Annuleren" } }}
>
    <RebaseCMS tableCustomizations={tableCustomizations}/>
    <RebaseShell title="My App"/>
</Rebase>
```

Las claves que omitas recurrirán al inglés, por lo que un conjunto parcial sigue
siendo una traducción funcional, no una rota.

### Dónde están las claves

La tabla completa es `RebaseTranslations`: una interfaz con todas las claves, para
que tu editor las autocomplete y cualquier error tipográfico sea un error de tipos.
Sus valores en inglés se encuentran en `packages/app/src/locales/en.ts`, que es la
referencia de lo que dice realmente cada clave.

Los nombres siguen la superficie a la que pertenecen: `save`, `cancel`,
`delete_confirmation_title` para el panel, `studio_*` para las herramientas de
desarrollador (`studio_tool_sql`, `studio_group_database`,
`studio_backups_denied_title`).

## Traducir tus propios componentes

`useTranslation()` te proporciona la misma tabla para que la lean tus vistas,
campos y acciones personalizados:

```tsx
import { useTranslation } from "@rebasepro/app";

function PublishButton() {
    const { t } = useTranslation();
    return <Button>{t("save")}</Button>;
}
```

La interpolación utiliza la misma sintaxis `{{name}}` que las cadenas integradas:

```tsx
t("add_to_field", { fieldName: "Tags" });
```

Tus propias claves se pasan a través de `translations` como cualquier otra: una
clave que Rebase no declare se seguirá resolviendo, por lo que puedes colocar
las cadenas de tus componentes en la misma tabla en lugar de ejecutar una
segunda solución de i18n en paralelo.

`t` también devuelve la propia clave cuando nada coincide, lo cual es la respuesta
directa y hace que una clave faltante sea visible en la interfaz de usuario en
lugar de quedar en blanco.

## Textos propios del UI kit

Algunas cadenas pertenecen a `@rebasepro/ui` directamente y no al panel de
administración: "No entries found", "All 12 entries loaded" y "Error loading data"
de las vistas de lista y tarjeta, el título de error de la tabla, los textos de
la barra de búsqueda y fechas relativas como "5m ago". Dentro de una aplicación
Rebase, provienen de las mismas traducciones (`no_entries_found`, `all_entries_loaded`,
`error_loading_data_message`, `search`, `clear_search`, `relative_*`) y siguen
el idioma como cualquier otra cadena.

Si utilizas el kit por separado, estará en inglés hasta que lo envuelvas en un
`UiLabelsProvider`. Cualquier etiqueta que omitas mantendrá su valor predeterminado
en inglés:

```tsx
import { UiLabelsProvider } from "@rebasepro/ui";

<UiLabelsProvider labels={{
    noEntriesFound: "Nessuna voce trovata",
    allEntriesLoaded: (count) => `Tutte le ${count} voci caricate`,
    relativeTime: { minutesAgo: (count) => `${count} min fa` }
}}>
    <ListView data={rows} renderRow={renderRow}/>
</UiLabelsProvider>
```

`useUiLabels()` lee las etiquetas vigentes, y `formatRelativeTime` de
`@rebasepro/utils` toma `labels: useUiLabels().relativeTime` para mostrar una fecha
de la misma manera.

## Los nombres de grupo no son etiquetas

El `group` de un `AppView` es un identificador: el menú lateral (drawer) se pliega
según él, la página de inicio de Studio se ordena según él y `navigationGroupMappings`
le asocia iconos. Traducirlo donde se declara romperá estas tres funcionalidades en
todos los idiomas excepto en aquel al que lo tradujiste.

Declara el grupo en inglés y deja que el encabezado se traduzca por sí mismo: los
grupos propios de Rebase tienen claves `studio_group_*` y se buscan por nombre;
un grupo personalizado se muestra tal como fue escrito.

```tsx
// Right: the name is stable, the heading is localized for the built-in groups.
{ slug: "queues", name: "Queues", group: "Compute", view: <QueuesView/> }
```
